2. 三種劇情：一筆交易的三種結局

2.1成功路徑（SAGA-001）：Try → Confirm

正常買入：帳戶先凍結金額（Try），Saga 收到 FUNDS_RESERVED 後下 Confirm 扣款，訂單成交。兩個資料庫沒有 XA，靠 Kafka 事件最終一致。

畫面標註

  1. 1總結列（綠）：Saga COMPLETED／訂單 FILLED／預留票 CONFIRMED
  2. 2Saga 流程：STARTED → ACCOUNT_TRYING → ACCOUNT_CONFIRMING → COMPLETED
  3. 3訂單結果：PENDING → FILLED（orderdb）
  4. 4預留票：TRYING → CONFIRMED（accountdb，Try 凍結、Confirm 扣款）

操作步驟

  1. 數量 1、價格 10000（預設值）
  2. 按綠色「成功路徑（SAGA-001）」
  3. 等頂部提示變綠

預期結果

Saga COMPLETED／訂單 FILLED／預留票 CONFIRMED；available 100000 → 90000（扣 10000）。

背後程式（hover 呼叫鏈 action:place）

只負責「啟動」：建立訂單＋Saga、RESERVE_FUNDS 進發件匣，HTTP 202 立即返回；之後全靠 Kafka 推進

入口HTTP POST /api/v1/trades
前台按 SAGA-001／SAGA-002／TCC-002 任一顆下單鈕：只啟動 Saga，HTTP 202 立即返回
  1. TradeController.place
    接收下單請求：@Valid 驗證後交給 SagaOrchestrator，回 202 Accepted
  2. SagaOrchestrator.start
    orderdb 同一 Local TX：建訂單＋Saga 實例 → 轉 ACCOUNT_TRYING → RESERVE_FUNDS 寫進發件匣
  3. OutboxPublisherService.append
    把命令寫進發件匣（outbox 表），與業務資料同一個 TX

2.2餘額不足（SAGA-002）：Try 失敗 → 補償

用 999999 的價格下單：帳戶 Try 失敗回 FUNDS_FAILED，Saga 把訂單標記失敗收尾。補償完成是「正確結局」，不是系統錯誤。

畫面標註

  1. 1總結列（橘）：Saga COMPENSATED／訂單 FAILED／預留票 TRY_FAILED
  2. 2Saga 走補償分岔：ACCOUNT_TRYING 之後 → COMPENSATING → COMPENSATED
  3. 3預留票：餘額不足，Try 直接失敗、沒有凍結任何金額

操作步驟

  1. 按黃色「餘額不足（SAGA-002）」（自動用 1×999999，結束後價格還原 10000）
  2. 等頂部提示變橘

預期結果

Saga COMPENSATED／訂單 FAILED／預留票 TRY_FAILED；available 維持 90000（沒有被扣）。

DASH-004

背後程式（hover 呼叫鏈 saga:COMPENSATED）

收到 FUNDS_FAILED／FUNDS_CANCELLED → 經 COMPENSATING 收尾，訂單同時標記失敗

入口KAFKA trading.saga.events
訂單側收到帳戶回報的結果事件（topic 名稱取自 trading.kafka.event-topic）
  1. SagaKafkaListeners.onEvent
    訂單側 Kafka 入口：消費帳戶回報的結果事件，交給 OrderSagaEventHandler
  2. OrderSagaEventHandler.onMessage
    依事件類型分派：FUNDS_RESERVED → onReserved、FUNDS_CONFIRMED → onConfirmed、失敗／取消 → 補償
  3. OrderMarkFailedAction.compensate
    補償動作：Saga 經 COMPENSATING 到 COMPENSATED、訂單標 FAILED（只動 orderdb）
  4. SagaInstance.transitionTo
    Saga 狀態機轉移；不允許的跳轉丟例外，狀態維持不變

3.3定格橫幅、慢動作重播、回到即時

重播讓你看清楚「預留票先變、Saga／訂單後跟上」的順序：兩個資料庫靠事件追上彼此。

畫面標註

  1. 1定格橫幅：目前停在第幾格、相對時間、那一格發生什麼
  2. 2慢動作重播：從第 1 格逐格播放（旁邊下拉選每格秒數）
  3. 3回到即時：離開定格，顯示最新狀態
  4. 4完成後自動重播：開著時，每次下單到終態會自動播一遍

操作步驟

  1. 按「慢動作重播」觀察三條 lane 逐格亮起
  2. 按「回到即時」結束定格

預期結果

重播時變動的 lane 會發藍光；播完自動回到即時。
